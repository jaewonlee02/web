
# 개인 프로필 소개 웹페이지 

## 기술 스택
- **Backend:** Node.js, Express
- **Frontend:** HTML, CSS, JavaScript, EJS

##  주요 기능
1. **동적 렌더링 (EJS)**
   - 서버(`app.js`)에서 전달받은 프로필 데이터(이름, 전공, 취미, 기술 스택 등)를 화면에 동적으로 렌더링합니다.
2. **다크모드 지원**
   - 우측 상단의 '다크모드 켜기/끄기' 버튼을 통해 라이트 테마와 다크 테마를 자유롭게 전환할 수 있습니다.
3. **게스트 메세지**
   - `prompt`를 이용해 방문자의 이름과 메시지를 입력받고, 화면에 즉시 띄워줍니다.
4. **비밀번호 확인 이벤트**
   - '좋아하는 음식' 버튼 클릭 시, 생일(0309)을 비밀번호로 입력해야만 결과를 확인할 수 있는 이벤트를 추가했습니다.
